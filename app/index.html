How it works

1 · Rate limit

Before any tokens leave, the vault calls bastion_guard::check_outflow by CPI. A refilling bucket caps outflows per mint, so any bug can only leak one window's worth.

2 · Circuit breaker

The monitor watches every transaction, failed ones too. A blocked over-limit drain is the attacker's first move, and it triggers an automatic pause by a key that can only pause.

3 · AI guardian

Claude reviews each incident, explains it in plain language, can pause gray-zone cases, and publishes its report onchain as a memo signed by the guardian.
